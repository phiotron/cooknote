# 2026-11-27 — Sửa lỗi nhập công thức từ web luôn báo 404

## Nguyên nhân

`WebViewEngine` coi **mọi** phản hồi HTTP ≥ 400 là lỗi của cả trang:

```dart
onHttpError: (error) {
  final code = error.response?.statusCode;
  if (code != null && code >= 400) { ... }   // cả favicon, ảnh, quảng cáo
}
```

Android gọi `onReceivedHttpError` cho từng tài nguyên con. Một favicon hay
ảnh kết quả tìm kiếm trả 404 là đủ để app phủ màn "Trang báo lỗi 404" dù
trang chính (DuckDuckGo) tải bình thường. `onWebResourceError` cũng có lỗi
tương tự với `isForMainFrame ?? true` trên nền tảng không điền trường này.

## Cách sửa

- Thêm `isMainFrameFailure`/`samePage` vào `browser_engine.dart`: lỗi chỉ
  thuộc trang chính khi nền tảng báo `isForMainFrame`, hoặc khi địa chỉ lỗi
  cùng giao thức + máy chủ + đường dẫn với trang đang tải (bỏ query).
- `WebViewEngine` lưu địa chỉ trang chính (`_mainFrame`) ở `load` và
  `onPageStarted`, rồi lọc cả `onHttpError` lẫn `onWebResourceError`.
- Trang thật sự trả 404 vẫn hiện lỗi như cũ (AC-21).
